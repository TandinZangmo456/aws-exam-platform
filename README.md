# AWS University Examination and Assignment Platform

## Project Overview

This project implements a secure, scalable and highly available
cloud-based examination and assignment submission platform for a university.

## Main Features

- Role-based authentication for students, tutors and administrators.
- Timed online examinations.
- Automatic answer saving every 30 seconds.
- Automatic MCQ marking.
- Assignment uploads using Amazon S3.
- Asynchronous processing and email notifications.
- Multi-AZ availability and fault tolerance.
- Monitoring, logging and security.
- Infrastructure as Code using Terraform.
- Automated deployment using GitHub Actions.

## Architecture

The platform is designed across two AWS Availability Zones.

See the architecture directory for the architecture diagram.
